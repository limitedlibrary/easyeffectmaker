# 簡単エフェクトメーカー #01：3D回転弾幕

ブラウザ上で3Dエフェクトを簡単に制作・シミュレーションし、その成果を
Blenderでのアニメーション制作に活用するためのツールです。

第一弾として、**発光する多数の弾が回転しながら連続発射される
3D回転弾幕エフェクト** を制作できます。将来的には雷・斬撃・爆発・魔法陣
など、他のエフェクトにも対応していく予定です。

サーバー不要・インストール不要で、GitHub Pages上でブラウザのみで動作します。
PC・スマートフォンの両方に対応しています。

## デモ / 使い方

1. 画面右側（スマホでは「設定」タブ）の **プリセット** から好きな弾幕を選ぶ
2. 各種パラメータをリアルタイムに調整しながら、左側（スマホでは「プレビュー」
   タブ）の3Dビューで確認する
3. 気に入った設定を **JSONを書き出す** ボタンで保存できる
4. 保存したJSONは **JSONを読み込む** ボタンでいつでも復元できる

画面下部のタイムラインで、再生・一時停止・停止・最初から再生・ループ・
再生速度の変更・任意の時刻へのシークができます。同じ設定・同じ再生時刻
であれば、常に同じ弾幕の状態が再現されます（決定論的シミュレーション）。

プレビュー3Dビュー内ではマウス/タッチでドラッグ・ピンチ操作すると、
演出設定内の「フリーカメラ」が有効になり、カメラを自由に動かして確認
できます（保存されるJSONには影響しません）。

## プリセット

- 放射状弾幕
- 螺旋状弾幕
- 二重回転弾幕
- 波状弾幕
- 多層立体弾幕

いずれのプリセットも、選択後に全パラメータを自由に変更できます。

## 開発方法

```bash
cd web
npm install
npm run dev       # 開発サーバー起動（ http://localhost:5173 ）
npm run typecheck # 型チェックのみ
npm run build     # 型チェック + 本番ビルド（web/dist に出力）
npm run preview   # ビルド結果をローカルで確認
npm test          # 自動テスト（決定論性・回転の正しさ・ゴールデンフィクスチャ・入力検証）
npm run gen:golden # ゴールデンフィクスチャ（web/test/golden/）の再生成
```

### 技術スタック

- TypeScript
- Three.js（レンダリング・ポストプロセス（Bloom）・OrbitControls）
- Vite（ビルド・開発サーバー）
- フレームワーク非依存の素のDOMでUIパネルを構築（追加の依存ライブラリなし）

### アーキテクチャ上の方針

シミュレーション計算（`web/src/core/`）とThree.js描画コード
（`web/src/render/`）を明確に分離しています。`core/` 配下は
Three.jsに一切依存しない純粋なTypeScriptで書かれており、将来
Blender用Pythonスクリプトへ移植する際の参照実装になります。
詳細は [`docs/json-spec.md`](docs/json-spec.md) を参照してください。

新しいエフェクト種別を追加する場合は、
`web/src/core/effects/` に `rotatingBarrage.ts` と同様の
「`computeFrame(doc, time) -> EffectFrame`」モジュールを追加し、
`web/src/core/effects/registry.ts` に登録するだけで、
UI・レンダラ側の変更を最小限に抑えて拡張できます。

## GitHub Pagesへのデプロイ

`web/vite.config.ts` は相対パス (`base: './'`) でビルドするため、
`web/dist` の中身をそのまま任意のサブパス（例:
`https://<user>.github.io/<repo>/`）にデプロイできます。

このリポジトリには `.github/workflows/deploy.yml` を同梱しており、
`main` ブランチへのpushをトリガーに `web/` をビルドして GitHub Pages
に自動デプロイします（リポジトリ設定で Pages のソースを
「GitHub Actions」に設定してください）。

## リポジトリ構成

```
web/        ブラウザ版アプリのソースコード（TypeScript / Three.js / Vite）
blender/    将来のBlender連携用（現時点ではプレースホルダ）
samples/    サンプルJSON（5プリセット分）
docs/       JSON仕様書など
README.md   このファイル
```

## 現時点での制約・未実装事項

- Blenderアドオン／Pythonインポーター／リアルタイム連携は今回のスコープ外
  です（`docs/json-spec.md` と `blender/README.md` に、次回実装する際の
  仕様を記載しています）。
- 対応エフェクトは現状「3D回転弾幕」のみです。他エフェクト（雷・斬撃・
  爆発・魔法陣）は未実装です。
- 弾の形状は「球・直方体・正八面体・光の粒（スプライト）」の4種類の
  プロシージャル形状のみで、カスタムメッシュやテクスチャの差し替えには
  対応していません。
- 軌跡・被弾判定・衝突などゲームロジックは対象外です（純粋な映像表現）。
- モバイル端末では画面サイズに応じてプレビューと設定パネルをタブ切り替え
  する構成にしていますが、非常に低スペックな端末でのパフォーマンスは
  未検証です。
